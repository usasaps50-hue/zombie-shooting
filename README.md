# ゾンビシューティング

Three.js製のブラウザ3Dゲーム。現在は一人称視点の移動のみ実装。

## 遊び方（ローカル）

```bash
npx --yes serve -l 5173 .
```

http://localhost:5173 を開き、画面をクリックして開始。

| 操作 | キー |
| --- | --- |
| 移動 | W / A / S / D |
| 視点 | マウス |
| ジャンプ | Space |
| ダッシュ | Shift |
| ポーズ | Esc |

## 構成

- `index.html` — 画面とUI（照準・オーバーレイ・HUD）
- `src/main.js` — シーン、ライト、地形、一人称操作、当たり判定
