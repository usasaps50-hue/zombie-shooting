# ゾンビシューティング

Three.js製のブラウザ3Dゲーム。ビルド不要の静的サイト（CDNのimportmapでThree.jsを読み込み）。

## 遊ぶ（公開ページ）

**<https://usasaps50-hue.github.io/zombie-shooting/>**

GitHub Pages で公開してあるので、スマホでもPCでも、どこからでも開ける。`main` に push すると自動で反映される。

- HTTPS なので、視点操作（Pointer Lock）・全画面・音・オンライン通信がすべて使える
- スマホは Safari で開いて「ホーム画面に追加」（→「スマホのホーム画面に追加する」）
- 一緒に遊ぶ人にも、このURLを教えるだけでよい

## 遊び方（ローカル）

```bash
npx --yes serve -l 5173 .
```

http://localhost:5173 を開く。待機ロビーで職業とアイテムを選び、スタート。

## デスクトップから起動する（macOS）

デスクトップに**通常ゾンビの顔のアイコン**のアプリを置いてある。ダブルクリックすると、小さなサーバーを立ててから既定のブラウザでゲームを開く（ブラウザは `file://` からモジュールを読めないので、サーバーが要る）。

- アイコンの元絵は `icon/zombie-face.png`（1024px）、macOS用は `icon/zombie.icns`
- **顔はゲーム中のモデルそのもの**。`tools/make-icon.html` をローカルサーバーで開くと、`src/zombie.js` から作り直せる
- ゲームのフォルダを移動したら、`tools/make-app.sh` を実行してアプリを作り直す

```bash
./tools/make-app.sh
```

サーバーはポート8765で動き、ゲームを閉じても残る。止めたいときは:

```bash
pkill -f "http.server 8765"
```

## スマホのホーム画面に追加する

iPhone の Safari で開いて、共有ボタン → **「ホーム画面に追加」**。**通常ゾンビの顔のアイコン**で並び、タップすると**Safari の枠なしの全画面**で起動する。

- iOS 用アイコンは `icon/apple-touch-icon.png`（180px）。**iOS は透明を黒く塗ってしまう**ので、背景を塗った専用の絵（`icon/zombie-face-solid.png`）から作っている
- Android の Chrome 用に `manifest.webmanifest`（192px・512px、全画面・横向き固定）も置いてある
- ブラウザのタブ用に `icon/favicon-32.png`

スマホでは、**公開ページ <https://usasaps50-hue.github.io/zombie-shooting/> をそのまま開けばよい**（同じWi-Fiにいる必要もない）。

手元で直したものを試したいときだけ、Mac の IP でつなぐ:

```bash
# Mac の IP を調べる
ipconfig getifaddr en0
```

スマホの Safari で `http://<いま出たIP>:8765/index.html` を開く（同じWi-Fiにいるとき）。

画面下のアイテム欄は、絵文字ではなく**実際の武器の3Dモデルを小さく描いた画像**を出している（`src/itemicon.js` がゲーム中と同じモデルから作るので、持ち物と見た目が必ず一致する）。

デバッグ用に `G` キーで自分に25ダメージ。

## スマホ

**横画面専用**。縦のまま開くと「横向きにしてください」と出る。スタートを押したときに全画面と横固定を要求するので、対応している端末（Android Chrome など）では自動で横になる。iPhone の Safari は画面回転ロックを切っておく必要がある。

- ノッチのある端末でも操作ボタンが隠れないよう、セーフエリアを避けて配置している
- スマホでは影の解像度と描画倍率を落として軽くしている
- 3D描画に **WebGL2** が必要。使えない端末では理由を書いた画面が出る（iPhone は iOS 15 以降の Safari、Android は最新の Chrome）

## 流れ

`タイトル` → `待機場（3Dマップ）` → `バトルゲートで合言葉を決める` → `バトル`

同じ合言葉を入れた人どうしが、同じ部屋で一緒に戦える（→「オンラインで一緒に遊ぶ」）。Supabase の設定がなければ、そのまま1人用として動く。

## 待機場

歩き回れる3Dの広場。真ん中の石畳には何も置いていないので、ぐるっと回って好きな方向へ行ける。

| 場所 | 方角 | できること |
| --- | --- | --- |
| アイテムショップ（ハルさん） | 西 | 持っていくアイテムを選ぶ（最大3つ） |
| クラスショップ（ミナさん） | 東 | 職業を選ぶ |
| レベルアップ所（ゲンさん） | 南 | コインで武器を強くする |
| バトルゲート | 北 | 合言葉を決めてバトルに出発する |
| あやしい端末 | 広場の左手前（北西・緑の光が目印） | 合言葉を入れると、指定した枚数のコインが出る |

- お店にはカウンターがあり、その内側に店員が立って**手を振っている**。近づくと画面に「◯◯（E）」と出るので、`E`（スマホは「使」）で話しかけると買い物の画面が開く
- 職業専用アイテム（衛生兵の包帯、建築士のハンマー）は、その職業を選ぶと自動で入る
- 待機場では体力・弾・素材の表示と戦闘用のボタンは出さない
- ポーズ画面の「待機場に戻る」で、バトル中でもいつでも戻れる

キャラクターには**目と口**をつけてある（自分・味方・店員のすべて）。

### チャット（待機場だけ）

画面の**左上**に、待機場にいる人みんなの発言が流れる。バトル中は出ない。

| したいこと | PC | スマホ |
| --- | --- | --- |
| 書きはじめる | `Enter` | 左上の「💬 話す」をタップ |
| 送る | もう一度 `Enter` | キーボードの送信 |
| やめる | `Esc` | 画面のどこかをタップ |

- **書いている間はゲームの操作が止まる。** `W` `A` `S` `D` も `Esc` もチャットに入るので、うっかり歩き出したりポーズになったりしない
- 名前の色は**名前から決まる**ので、同じ人はいつも同じ色になる
- 話した言葉は、**その人の頭の上にもふきだしで6秒**出る（3行まで。長い言葉は「…」で切る）
- しばらく誰も話さないと、流れた文字は薄くなって景色を隠さない
- 誰かが待機場に入った・出ていったも、この欄に流れる
- 1回に送れるのは**90文字**まで。連打よけに**0.8秒に1回**まで

届いた文字は必ず `textContent` として入れているので、他の人がタグのような文字を送ってきても、**そのままの文字として表示されるだけ**（画面を壊されない）。

### あやしい端末（広場の左手前）

**待機場**に入って、**そのまま左を向くとすぐ見える**。広場のふちに立っていて、**緑に光る柱と「？？？」の看板**が目印。石畳の道もそこへ伸びている。

`E`（スマホは「使」）で開き、**合言葉と、ほしいコインの枚数**を入れる。合言葉が合っていればその枚数がそのままもらえる（大文字小文字は区別しない）。1回に出せるのは999999枚まで。

合言葉は `src/shop.js` の `SECRET_PASS` に書いてある。

## オンラインで一緒に遊ぶ

同じ合言葉をバトルゲートで入れた人どうしが、同じ部屋で一緒に戦えます。通信には **Supabase Realtime** を使っています（データベースもログインも使いません）。

**設定はもう入っています**（`src/data/netconfig.js`）。作り直すときのために、手順も残しておきます。

### 1. Supabase の準備（1回だけ・無料）

1. <https://supabase.com> を開いて、GitHub アカウントなどで **Sign up**（無料）
2. **New project** を押す。名前は何でもよく、リージョンは **Northeast Asia (Tokyo)** を選ぶと日本からは速い
3. データベースのパスワードを求められるので、適当に作って控えておく（このゲームでは使いませんが、プロジェクト作成に必要です）
4. プロジェクトができるまで1〜2分待つ
5. 左下の **Project Settings** → **API Keys** を開く
6. **Project URL**（`https://なんとか.supabase.co`）と、**Publishable key**（または `anon` `public` と書かれたキー）をコピーする

⚠️ `service_role` / `secret` と書かれたキーは絶対に使わないでください。ブラウザに置いてよいのは Publishable（anon）キーだけです。

### 2. ゲームに貼る

`src/data/netconfig.js` を開いて、上の2つを貼ります。

```js
export const SUPABASE_URL = 'https://なんとか.supabase.co';
export const SUPABASE_KEY = 'sb_publishable_なんとか';
```

これだけです。テーブルを作ったり、SQL を書いたりする必要はありません。

### 待機場では全員が同じ部屋

**待機場（3Dの広場）は、合言葉に関係なくみんな同じ部屋**（`HUB_ROOM`）に集まる。誰かが遊んでいれば、買い物をしながらその姿が見える。

バトルに出発すると、そこで入れた**合言葉ごとの部屋に移る**ので、一緒に戦いたい人とは同じ合言葉を決めておく。

### 3. 遊ぶ

0. 一緒に遊ぶ人に <https://usasaps50-hue.github.io/zombie-shooting/> を開いてもらう
1. 待機場の奥の **バトルゲート** で、**なまえ** と **合言葉** を入れて出発する
2. 一緒に遊ぶ人にも、**同じ合言葉**を入れてもらう
3. つながると、画面の右上に部屋の人数と名前が出ます（👑 が付いている人が「親」）

貼る前でも、そのまま**ひとりで**遊べます（ゲートに「⚪ ひとりで遊ぶ」と出ます）。

### 何が共有されるか

| 共有される | 各自の画面だけ |
| --- | --- |
| プレイヤーの位置・向き・武器・モーション・HP | 持っている素材とコイン |
| ゾンビ（種類・位置・HP・モーション） | 武器レベル |
| ウェーブの進行と残り数 | 必殺技のゲージ |
| 建物（壁・タレット・野戦病院・ゴッドタレット） | |
| 敵の弾と矢、地割れ、着地の印 | |
| ダウンと蘇生（衛生兵が他の人を助け起こせる） | |
| 拡声器の効果（範囲内の仲間に飛ぶ） | |
| ドローン（親が動かすので、全員に見える） | |
| ネクロマンサーの味方（親が動かすので、全員に見える） | |
| チームロッドの召集（子が使っても親が味方を動かす） | |
| 倒したゾンビのコイン（全員が同じだけもらう） | |
| **待機場にいる人（合言葉に関係なく全員）** | |
| **待機場のチャット（発言と、頭の上のふきだし）** | |

倒したゾンビの**コインは、誰が倒しても部屋にいる全員がもらいます**（拾いに行かなくていい）。
素材と、武器についている「倒すと回復」などの効果は、**とどめを刺した人**だけです。

### しくみ

**部屋に最初に入った人が「親」**になり、その人の端末だけがゾンビとウェーブを動かします。他の人（子）はゾンビを動かさず、届いた場所へなじませて表示するだけです。

- 子がゾンビを撃つと「当てた」と親に伝え、**HPを減らすのは親**。だから全員が同じHPを見ます
- 子が建物を建てると「ここに建てたい」と親に伝え、**置けるかどうかも親が決める**
- 自分のHPだけは自分の端末が持っていて、親から「やられた」と伝えられて減ります
- **親が抜けたら、次に早く入った人が自動で親を引き継ぎます**（ゾンビはその場のまま続きます）

途中から入った人にも、いまのゾンビと建物がまとめて届くので、そのまま合流できます。

### 通信量の目安

Supabase の無料プランは **100メッセージ/秒**、**200同時接続**、**2,000,000メッセージ/月** です。このゲームの送り方だと：

| 人数 | メッセージ/秒 |
| --- | --- |
| 2人 | 約34 |
| 4人 | 約58 |
| 6人 | 約64 |
| 8人 | 約58 |

1回の世界の状態は約250〜700バイト、合計で毎秒2KBほどです。**月の合計だと、4人で遊んで10時間ぶんくらい**で無料枠を使い切る計算になります。足りなければ `src/data/netconfig.js` の `playerHz` と `worldHz` を下げてください（数字を下げるほど、他の人の動きがカクつきます）。

人数が5人以上になると、1人あたりの送信を自動で減らします（`playerHz()`）。

### 3本のロッドと味方（ネクロマンサー専用）

リボーンロッドとデスロッドは、どちらも**狙った所で爆ぜる範囲魔法**を撃つ。撃ちたい方向を見て攻撃ボタン。
（チームロッドは攻撃ではなく、味方を呼び集める杖。下に書いてある）

**着弾点は、照準の先で最初にぶつかる所**：ゾンビ・壁・建てたもの・地面のうち一番手前を選び、そこから真下の床に魔法陣を描く。足元を見れば足元に、遠くを見れば射程いっぱい（26m）まで飛ぶ。壁ごしには撃てない。

杖の先から着弾点まで光の筋が走り、そこに魔法陣が広がって**炎が立ちのぼる**（リボーンは青、デスは紫）。

**リボーンロッド**（青い光の玉）

| Lv | コイン | ダメージ | 間隔 | 半径 | 味方になる確率 |
| --- | --- | --- | --- | --- | --- |
| 1 | 最初から | 8 | 1.4秒 | 2.6m | 20% |
| 2 | 250 | 11 | 1.2秒 | 2.8m | 30% |
| 3 | 450 | 14 | 1.0秒 | 3.0m | 35% |
| 4 | 700 | 17 | 0.8秒 | 3.2m | 40% |
| 5 | 1000 | **20** | **0.6秒** | 3.5m | **50%**（金色） |

**デスロッド**（ドクロと紫の光）

| Lv | コイン | ダメージ | 間隔 | 半径 |
| --- | --- | --- | --- | --- |
| 1 | 最初から | 16 | 8.0秒 | 3.0m |
| 2 | 250 | 22 | 7.0秒 | 3.3m |
| 3 | 450 | 28 | 6.5秒 | 3.7m |
| 4 | 700 | 34 | 5.5秒 | 4.1m |
| 5 | 1000 | **40** | **5.0秒** | 4.5m（金色） |

**味方（ミニオン）**

リボーンロッドでとどめを刺したゾンビは、確率で**最大HPの半分**で起き上がって味方になる。

- **主人にはついてこない。** 起こした場所のあたりに残って、そこを守る
- **16m以内に敵がいると、そちらへ走って殴りに行く**（1発12ダメージ／1.2秒に1回）。敵がいなくなったらその場で待つ
- 呼び戻したいときは**チームロッド**を使う（下）
- 見た目は元のゾンビのまま。頭の上に**青い魂の炎**、足元に青い輪が出る
- **味方もゾンビに殴られて倒れる。** 連れて歩ける数に**上限はない**（増やしすぎると重くなるかもしれない）

**チームロッド**（緑の旗、ネクロマンサー専用・最初から持っている）

旗を高くかかげて振ると、**散らばった自分の味方が、いっせいに自分のところへ集まってくる**。
呼ばれた味方は敵を追うのをやめて走ってきて、着いたらそこで待つ。

| Lv | コイン | 届く距離 | 間隔 | 集まった味方の回復 |
| --- | --- | --- | --- | --- |
| 1 | 最初から | 30m | 20秒 | なし |
| 2 | 200 | 40m | 16秒 | なし |
| 3 | 400 | 50m | 13秒 | 最大HPの20% |
| 4 | 700 | 70m | 10秒 | 最大HPの35% |
| 5 | 1000 | **マップ全体** | **8秒** | **最大HPの50%**（金色） |

呼べるのは**自分が起こした味方だけ**。他の人の味方は動かない。

### ナイフと血のゲージ（犯罪者専用）

**相手のいまのHPを削る**武器。硬いゾンビほどよく効くが、削って残りが減るほど1発の威力も落ちていく。

与えるダメージ = **相手のいまのHP × 割合 × （血のゲージ ÷ 100） ＋ 固定ぶん**

| Lv | コイン | 割合＋固定 | 攻撃間隔 | 血の増え方 | ほか |
| --- | --- | --- | --- | --- | --- |
| 1 | 最初から | HPの25%＋10 | 1.0秒 | +5 | — |
| 2 | 200 | HPの25%＋11 | 0.8秒 | +6 | 移動速度+20% |
| 3 | 400 | 〃 | 0.8秒 | +6 | スキル「血の解放」 |
| 4 | 700 | **HPの39%＋30** | 0.8秒 | +6 | — |
| 5 | 1000 | 〃 | **0.6秒** | +6 | **見た目が金色** |

**血のゲージ（上限100）**は当てるたびに溜まり、次の2つに効く。

- **威力**：表の数字は**ゲージが満タンのとき**のもの。ゲージ0だと固定ぶんしか出ない（Lv4なら30、満タンで108／相手HP200のとき）
- **移動速度**：ゲージに比例して上がり、**満タンで+50%**

**血の解放（Lv3〜）**：`F`（スマホは「技」）で発動。**0.1秒に1ずつゲージが減っていき、その間はナイフを当てるたびにHPが5回復する**。満タンなら10秒続く。減るぶん威力と速度は落ちていくので、いつ使うかが読みどころ。

### 拡声器（サポート武器）

攻撃はできないが、**自分と、声の届く仲間（14m以内）をまとめて強くする**。攻撃ボタンで使い、**15秒に1回**。効果は**10秒**続く。

| Lv | コイン | 効果（10秒間） |
| --- | --- | --- |
| 1 | 200で購入 | 移動速度+10% |
| 2 | 150 | 移動速度+15% |
| 3 | 300 | 攻撃力+10% が加わる |
| 4 | 600 | 受けるダメージ-5% が加わる |
| 5 | 900 | **見た目が金色**／**被ダメージ-10%・移動速度+20%・攻撃力+20%** |

- 使うと**金色の輪が広がって**、効果が届く範囲が見える。かかっている人の足元には金の輪が出る
- **マップにいるゾンビ全部が、鳴らした場所に集まってくる**（25秒間）。安全なときに使うこと
- 効果が重なったときは**強いほうが残る**（弱い拡声器で上書きされない）
- オンラインでは、範囲内の仲間全員に同じ効果が飛ぶ

### 効果音

音源ファイルは持たず、**その場で波形を合成して鳴らしている**（`src/audio.js`）。ビルド工程のない構成なので、mp3 などを増やさずに済ませたい。

- 銃・サイレンサー・弾切れ・リロード／シャベルの風切りと打撃／ヘッドショット
- ロッドの詠唱と着弾、味方が起き上がる音
- タレットとドローンの発射音／ゾンビが腕を振りかぶる音（当たる前に鳴るのでよけられる）
- ゾンビのうなり・断末魔・弓・地中に潜る音
- 爆発・ミュータントの着地・建てる・壊れる
- 被弾・ダウン・蘇生・回復・コイン・ウェーブ開始・必殺技・拡声器
- **自分以外の音は3D**。遠いほど小さく、左右にふって鳴る（`playAt`）

ブラウザは操作があるまで音を出せないので、最初のクリックやキー入力で用意する。**M キーで消せる**。

### 音とヘッドショット

- 銃を撃つと、その音が届いた範囲のゾンビが**音のした場所へ寄ってくる**（8秒間）。まだ見つかっていないゾンビも引き寄せられる
- 音の届く距離：AK47 34m ＞ ピストル 22m ＞ AK47サイレンサー 10m ＞ ピストルサイレンサー 6m ＞ シャベル 3m
- サイレンサーを付けても**近くのゾンビには気づかれる**
- 頭（身長の78%より上）に当てると**ダメージ1.1倍**。当たった場所で光がはじけ、「ヘッドショット！」と出る
- **装甲を着たゾンビは、銃とタレットのダメージが15%減る**（爆発やシャベルは減らない）

### 構える（ズーム）

銃を持っているときだけ、**右クリック**（スマホは「狙」ボタン）を押している間だけ構える。画角が75度→42度に狭まってズームし、銃が画面の真ん中に来る。

### ローリングスマッシュ（シャベル Lv3〜）

攻撃を**5回当てる**と使えるようになる、攻撃ボタンとは別のスキル。`F`（スマホは「技」ボタン）で発動すると、回転しながらシャベルを振り回して**全方向のゾンビ**を巻き込む。シャベルLv5の吸収（与ダメージの半分を回復）はこの技にも乗る。

### 俊足ゾンビ（赤）

牙をむいて目を吊り上げた赤いゾンビ。**HPは50と柔らかいかわりに、走る速さが通常の2倍（5.6m/s）** で、手足の振りも1.9倍速い。ダッシュ（8m/s）でないと振り切れない。

### 紫ゾンビ

**HPが半分を切ると、50%の確率で1度だけ地中にもぐる。** もぐっている間は攻撃が当たらず、3.5秒後に**プレイヤーの3〜5m以内**の地面から飛び出してくる。

- 出てくる場所は、プレイヤーと同じ高さの床があって、壁の中にならない所を選ぶ
- **出てから2秒間は身構えているだけで攻撃してこない。** この2秒が逃げるか撃ち込むかの時間
- もぐるときも出るときも、土けむりと土の粒が舞う

### ガンマゾンビ

カウボーイ姿（テンガロンハット・革ベスト・バンダナ・チャップス・保安官バッジ）で、右手にリボルバーを持っている。

- **索敵範囲が75mと非常に広い。** さらに **一度見つけた相手は、範囲の外に出ても見失わない**
- 見つけた相手の居場所は**2秒おきに仲間へ伝わる**ので、離れたゾンビもそちらへ集まってくる
- **距離11mを保って撃つ。** それより近づかれても後ろへは下がらず、その場で撃ち続ける
- **歩きながら撃てる**（1.5〜3秒に1発／火力10／射程30m）。撃つと銃口が跳ね上がる
- 壁にぶつかると、左右に開いた向きを試して**回り込んで**近づく
- 壁ごしには撃たない（見通しが通っているときだけ撃つ）

### スケルトン

骨だけの体。どくろの眼窩が赤く光り、あごがカタカタ鳴る。**棒（骨のこん棒）で殴るタイプと、弓を撃つタイプ**がいる。

- **倒しても50%の確率で1度だけ、HP半分（50）で組み上がって起き上がる。** 散らばった骨が震えながら引き寄せられ、緑に光って立ち上がる。組み上がっている間は攻撃が当たらない
- 棒は火力5・射程2.2m。弓は火力6・射程26mで、**引き絞る間は足を止める**（撃ってから次まで1.8〜3.2秒）
- 弓は距離15mまで詰めてから撃つ。矢は山なりに飛ぶので、走ってよければ当たらない

### ミュータントゾンビ

身長2.6mの大型（通常ゾンビは1.8m）。前かがみで腕が太く、上半身裸に破れた短パン。

- 攻撃は**両腕の叩きつけ**。当たると**地面が割れて**、放射状のヒビと砂ぼこりが広がる（火力10／射程3m）
- 壁やタレットには1発40ダメージ。**ドローンも壊せる**（1発20ダメージ＝一撃）
- **HPが2割を切ると、10%の確率で1度だけ大ジャンプする。** 味方・タレット・ドローンが一番密集している場所（射程26m以内）を狙って跳び、着地点の半径5mに50ダメージ＋地割れ。抽選に外れた個体はもう跳ばない
- **跳ぶ前に1.5秒の溜めがある。** 低く沈み込んで体が赤熱し、同時に**落ちてくる場所へ赤い印**が出る。印の内側の円が広がりきったときが着地なので、そこから離れればよけられる
- **溜めの間もジャンプ中も無敵**で、弾も爆発も当たらない（溜めのうちに倒すことはできない）

### 吹き飛ばしと壁

シャベルや爆発でゾンビを吹き飛ばすとき、**移動は必ず壁の判定を通す**。通さずに座標を足すと壁にめり込む。それでも重なってしまったとき（ミュータントの着地など）のために、`#unstick()` が近くの空いている場所へ押し出す。

### ゾンビの挙動

視界（14m）の外では、その場のまわりを適当に歩き回る。プレイヤーが視界に入ると最短距離で追いかけ、射程2mまで来たら**立ち止まって**腕を振り下ろす（火力5、1振りごとに1.2秒休む）。建物や瓦礫は避けて回り込む。倒すと素材とコインを落とす。

**相手を見つけていないときは、広場の真ん中（半径10m）を目指して歩く。** トンネルから出たあと散らばらず、中央に集まってくる。

**近くに建てたものがあれば、そちらを先に壊す。** 11m以内にあって、しかもプレイヤーより近い建物を狙う（`BUILD_LURE`）。**タレットは3m近くにあるものとして扱う**ので、撃ち返してくるタレットが優先して壊される。壁を置けばゾンビをそこへ引きつけられる。

**ドローンを落とせるのはミュータント（20）・ガンマゾンビ（10）・弓スケルトン（6）**。ガンマの弾と弓スケルトンの矢は、飛んでいく途中でドローンに当たる。

**殴っている途中で攻撃を受けると、その振りは中断される。** モーションが「被弾」に切り替わったら、攻撃をやめて仕切り直す（そうしないと「振り終わり」が来ず、その場から動けなくなる）。これはゾンビにも味方にも同じように効く。

**ゾンビも階段を上る。** 高さ0.6m以下の段差は当たり判定を素通りするので、階段はそのまま歩いて上れる。**上りはじめた階段は、上りきるまで乗り換えない**（途中で別の階段へ向かうと、いまの階段の横へ落ちてしまうため）。廃墟の屋上へ行く階段は2階の床から始まるので、1階のゾンビはまず正面の階段で2階へ上がってから使う。

さらに、**相手が自分より高いところにいると分かると、まず階段の下を目指して歩く**（`world.js` が階段の入口と出口を覚えていて、上りきれる階段の中から一番近いものを選ぶ）。その途中に建てた壁があれば、**壊してから**進む。屋上まで追ってくるので、高台に登っても安全ではない。

## ウェーブ

バトルはウェーブ制。決まった数を倒しきると次のウェーブに進み、**クリアごとにコイン+10**。

出てくる数は `5 × ウェーブ`。ウェーブ1は5体、2は10体、10は50体、20は100体。

**5ウェーブごとにゾンビのHPが元の50%ずつ増える**（W5〜9は1.5倍、W10〜14は2倍、W15〜19は2.5倍…）。

- **一度に出るのは20体まで。** 2秒おきに5体ずつ、4方向のトンネルから小分けに湧く
- ウェーブが進むほど**強いゾンビが主力**になる。ウェーブ1は通常ゾンビだけ。2で俊足と索敵、3で銀装甲、4で紫、5でスケルトン、6で弓スケルトン、7でミュータント、8でガンマゾンビが混じりはじめる（`src/data/waves.js` の `SPAWN_TABLE` の `from`）
- ウェーブとウェーブの間は6秒の休み。画面上の表示でカウントダウンする

### 軽くするための工夫

20体が同時に動いても重くならないよう、こうしている。

- **ゾンビを作り直さない。** 20体ぶんのモデルを最初に作って使い回す（倒れて消えた個体が次の湧きで再利用される）。種類が変わるときだけ作り直す
- **同じ形は共有する。** 手足や胴の箱は大きさごとに1つだけ作って全員で使う
- **影は胴と頭だけ。** 手足は影を落とさない。スマホでは全部オフ
- **遠いゾンビは3フレームに1回しか考えない**（そのぶん1回の歩幅を3倍にするので、動きは変わらない）

## マップ

廃墟の街。**真ん中は何も置かない広場**にしてあり、そこから十字に大通りが伸びている。

- **4方向のトンネル**（東西南北）。ウェーブのゾンビはここから出てくる
- **登れる廃墟（大）** 1つ。2階建てで、正面の階段で2階へ、建物の中の階段で屋上へ上がれる。屋上にはふちの壁がある
- **登れる足場** 3つ。高さ2mの台で、広場を向いた階段から上がる
- 廃ビルが15棟ほど。こちらは登れない飾りだが、**窓が付いている**（割れて真っ暗な窓も混ざる）
- 転がった瓦礫（当たり判定なし）

高いところへは**階段で上る**（ジャンプは要らない）。段差0.6m以下は自動で上れるようになっている。

**高台の上にも壁・タレット・野戦病院・ゴッドタレットを建てられる。** 置ける高さはその場所の床に自動で合う。

### 建築

| 建てるもの | コスト | HP | 同時に置ける数 |
| --- | --- | --- | --- |
| 木の壁 | 木100 | 150 | 5 |
| レンガの壁 | レンガ100 | 300 | 5 |
| 鉄の壁 | 鉄100 | 600 | 5 |
| タレット | レンガ30＋鉄20 | 75 | 5 |

ハンマーを持つと置ける場所が半透明で表示され（緑＝置ける／赤＝置けない）、左クリックで設置。R で木→レンガ→鉄→タレットと切り替わる。素材は画面左下に出る。

**上限まで置いた状態でもう1つ建てると、その種類の一番古いものが消えて置き換わる。** 上限は種類ごとに別々なので、木5枚＋レンガ5枚＋鉄5枚＋タレット5個を同時に置ける。いま何個置いているかは、ハンマーを持っているときに画面下（例：`3/5`）に出る。

建造物は頭の上に残りHPが出るので、どれが壊されかけているか分かる。

**建てた壁はゾンビだけを止める。仲間はそのまますり抜けられる。**

タレットは射程22m内のゾンビを自動で狙い、0.1秒ごとに火力3の弾を撃つ。30発撃つと2秒休む。ピストルもタレットも、撃つと銃口に爆発のようなエフェクトが出て、黄色い弾道が着弾点まで伸びる（他のプレイヤーからも見える）。

いまレンガと鉄を手に入れる手段はないので、建築士は動作確認用に最初から レンガ60・鉄40 を持っている。

### 必殺技

職業ごとに1つ。画面左下（スマホは左上）のゲージが満タンになると `Q`／「必殺」で撃てる。貯まり方は職業ごとに違う。

| 職業 | 必殺技 | ゲージの貯まり方 | 効果 |
| --- | --- | --- | --- |
| 一般兵 | ボム | 与えたダメージ合計250 | 一番近いゾンビに山なりに投げる。爆発で範囲4.5mに50ダメージ |
| 衛生兵 | 野戦病院 | 回復した合計100 | 目の前に小さな病院（HP50）を建てる。半径5m以内の味方とタレットを毎秒8回復 |
| 犯罪者 | 血の宴 | 与えたダメージ合計200 | 血のゲージが一気に満タンになり、HPも40回復する |
| ネクロマンサー | 影の軍勢 | **リボーンロッドで5体 味方にする** | 真っ黒な影の味方を3体呼ぶ（HP50）。**いる間、敵と味方の位置がレーダーに映る** |
| 建築士 | ゴッドタレット | 30秒（開始時は半分から） | **運任せ。** 30%でドローン3機、30%でロケット砲、40%で失敗 |

- 蘇生は「その味方のHPぶんを回復した」ものとして衛生兵のゲージに入る（包帯はその場で回復した量だけ）
- 野戦病院はゾンビに壊されると効果を失う。病院自身の回復ではゲージは貯まらない
- **失敗しても必殺技ゲージは消える。** 何が出るかは撃ってからのお楽しみ
- ロケット砲（HP75）は射程26m、5秒に1発、爆発範囲2.4m（ボムより小さい）で30ダメージ。壊されるまで撃ち続ける。3基まで
- ドローン（HP20、頭の上にHPが出る）は自分のまわりを回りながら、射程18mの敵に0.5秒ごとに10ダメージ。**当たりを引くたびに3機ずつ増え、6機を超えると古い機から消える**
- ドローンとロケット砲は別々に出るので、どちらか片方だけを持つこともある
- 野戦病院も3つまで

## 構成

- `index.html` / `style.css` — ロビー・HUD・スマホ操作UI
- `src/main.js` — 全体の進行、射撃判定、蘇生・回復の長押し処理
- `src/world.js` — シーン、ライト、地形、当たり判定用のコライダー
- `src/player.js` — 移動・視点・HP・ダウン状態
- `src/input.js` — キーボード / マウス / タッチ入力
- `src/device.js` — タッチ端末かどうかの判定と、描画品質の設定
- `src/weapons.js` — 装備スロット、弾数、リロード、モーションの進行度
- `src/viewmodel.js` — 一人称のアイテム表示とモーション
- `src/avatar.js` — 三人称の人型リグと、一人称と同じモーション
- `src/entities.js` — 味方（三人称デモ）とゾンビのAI
- `src/zombie.js` — 人型ゾンビのモデルと待機／歩き／攻撃／被弾／死亡／地中もぐり／出現モーション。カウボーイのそうび（ガンマゾンビ）と構え・反動もここ
- `src/skeleton.js` — スケルトンのモデルと、棒／弓／崩れ落ち／組み上がりのモーション
- `src/mutant.js` — ミュータントゾンビのモデルとモーション（溜めとジャンプを含む）
- `src/enemyshots.js` — ゾンビ側の飛び道具（ガンマの弾、スケルトンの矢）
- `src/audio.js` — 効果音（波形をその場で合成する。音源ファイルは持たない）
- `src/minion.js` — ネクロマンサーの味方（ついてくる／敵を倒しに行く／戻る）
- `src/effects.js` — 弾道、銃口の爆発、シャベルの薙ぎ跡、着地の印、土けむり、拡声器の輪、魔法陣
- `src/build.js` — ハンマーの照準（置ける場所の判定とプレビュー）と素材の出し入れ
- `src/structures.js` — 壁・タレット・野戦病院・ゴッドタレットのモデル、耐久、射撃処理
- `src/ultimates.js` — 必殺技のゲージ、ボムとロケットの弾道、ドローン
- `src/label.js` — 頭の上に出る文字（ゾンビと建造物のHP表示で共用）
- `src/hub.js` — 待機場のマップ（店・ゲート・店員・景色）
- `src/shop.js` — 待機場のお店の画面
- `src/net.js` — Supabase Realtime の出入口（部屋に入る／送る／受け取る、親を決める）
- `src/netsync.js` — 世界のようす（ゾンビ・建物・ウェーブ）をまとめる／取り込む
- `src/remote.js` — 他のプレイヤーの見た目と、位置のなじませ方
- `src/itemicon.js` — 武器の3Dモデルを小さく描いてHUD用の画像にする
- `src/waves.js` — ウェーブの進行（小分けの湧き、クリア判定）
- `src/textures.js` — canvas で描くテクスチャと、共有する箱の形
- `src/progress.js` — コインと武器レベル（ブラウザへの保存もここ）
- `src/lobby.js` / `src/hud.js` — 画面まわり
- `src/data/items.js` / `src/data/jobs.js` / `src/data/builds.js` / `src/data/ultimates.js` / `src/data/upgrades.js` / `src/data/waves.js` — アイテム・職業・建築物・必殺技・レベルアップ・ウェーブの定義（追加はここ）
- `src/data/netconfig.js` — **Supabase の URL とキーを貼るところ**。通信の細かさもここで変えられる

### アイテムを追加するには

1. `src/data/items.js` に定義を足して `SELECTABLE_ITEMS` に入れる
2. `src/viewmodel.js` の `createItemMesh()` に見た目を足す（一人称・三人称で共用）
